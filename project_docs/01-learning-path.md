# TravelAgent 学习路径草案

本文档是早期学习路径草案。当前仓库只搭建项目架构，不实现任何具体 lesson。正式课程路线以 [course-roadmap.md](course-roadmap.md) 为准。

## 学习主线

TravelAgent 以旅游规划业务为连续主线，逐步学习 Agent 技术：

1. 业务建模：理解旅游规划中的用户需求、约束、行程、预算和风险。
2. 需求澄清：从模糊自然语言中识别缺失信息并追问。
3. LLM 接入：使用 DeepSeek 生成结构化草案。
4. 工具调用：接入高德地图和和风天气。
5. ReAct：让 Agent 根据中间观察动态决定下一步。
6. Planning：先拆解复杂规划任务，再逐项执行。
7. RAG：检索目的地资料、攻略和政策。
8. Memory：保存并复用用户长期偏好。
9. Multi-Agent：用研究员、规划师、预算员、审稿员协作。
10. Evaluation：用任务集和规则评估旅行方案质量。
11. Production：预留 FastAPI/Web 服务化能力。
