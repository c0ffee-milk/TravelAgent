# Lessons

本目录用于后续按需生成具体课程。

当前已创建：

- `lesson_00_project_bootstrap/`：项目启动与业务建模，目前只包含 `README.md` 和 `lesson_plan.md`。

后续只有当用户明确要求生成某一课时，才创建对应目录、课案、代码、练习和验收标准。

每个 lesson 默认结构：

```text
lesson_00_topic_name/
  README.md
  lesson_plan.md
  code/
  exercises.md
  acceptance.md
```

所有 lesson 必须围绕同一个旅游规划业务逐步升级。
